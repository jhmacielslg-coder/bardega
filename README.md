# 🍻 BARDEGA — Cardápio Digital & Delivery

Cardápio digital moderno, responsivo e intuitivo desenvolvido para o bar e conveniência **BARDEGA** em Formosa/GO.

## 🚀 Tecnologias
- **Vite** + **JavaScript Vanilla**
- **HTML5 & CSS3 Moderno** (design responsivo, paleta temática `#983610`, micro-animações)
- **Integração WhatsApp** (geração automática de pedidos formatados)
- **GitHub Actions & GitHub Pages** (Deploy contínuo automatizado)

## 📌 Funcionalidades
- 📋 Categorias dinâmicas com ícones (Porções, Caldos, Bebidas)
- 🔍 Busca em tempo real com limpeza rápida
- 🍲 Modal detalhado com foto, seleção de sabores/opções e observações
- 🛒 Carrinho interativo com badge dinâmico, ajuste de quantidade e subtotal
- 💰 Informações de entrega (Taxa fixa R$ 6,00 | Tempo: 40–50 min)
- 📱 Chave Pix com cópia em 1 clique
- 💬 Envio do pedido diretamente para o WhatsApp do estabelecimento

## 🛠️ Comandos

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção (pasta dist/)
npm run build

# Pré-visualizar build de produção
npm run preview
```
